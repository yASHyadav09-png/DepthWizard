# sample_data

Drop a few non-georeferenced **JPG / PNG** images here to demo the Stage 1 pipeline.

Images that show the relative-height idea well:

- oblique or near-nadir aerial / drone shots of a built-up area
- urban street or rooftop views with clear tall structures
- landscapes with an obvious foreground/background separation

Keep them small (a few hundred KB each) — **do not commit large datasets or
model weights.** GAMUS, SRTM tiles and LiDAR reference data belong to later
stages and are excluded by `.gitignore`.

> Stage 1 accepts JPG and PNG only. GeoTIFF support arrives with the
> georeferenced pipeline in a later stage.
